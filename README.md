Peyvand is a production‑grade, single‑file Telegram/Bale bot that combines a full relationship manager with an anonymous chat engine. It guides users through a smart onboarding process—collecting gender, name, and birthday in both Gregorian and Jalali formats—then adapts its interface to the user’s status. Coupled partners get a shared “days together” counter, a daily mood tracker, and an automatic anniversary reminder system. Single users can enter a matchmaking queue that pairs them using gender preference, age range, and a dynamic reputation score. All anonymous chat sessions support rich media forwarding, reply context preservation, message deletion, and an in‑chat Truth or Dare mini‑game, while post‑chat match requests allow pairs to transition to an official relationship with one tap.

The bot is built entirely inside `main.py` with no external modules beyond the standard `pyTelegramBotAPI`, `python-dotenv`, and `jdatetime` libraries. Persistent data lives in a SQLite database (`peyvand.db`) with `users` and `notifications` tables, while active chat sessions and user score histories are stored as JSON files. In‑memory Python structures (`WAITING_QUEUE` and `ACTIVE_CHATS`) handle transient matching and session state, making the bot restart‑resilient for most operations. The UI/UX follows a conversational wizard pattern with context‑aware menus, inline age sliders, and clear error recovery, ensuring a smooth experience whether someone is celebrating an anniversary or talking to a stranger for the first time.
